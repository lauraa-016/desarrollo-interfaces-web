## 📌 Sobre este repositorio

Este repositorio reúne el trabajo realizado en el módulo de **Desarrollo de Interfaces Web (DIW)** durante el ciclo formativo de **Desarrollo de Aplicaciones Web**.

Aquí se irán almacenando diferentes ejercicios, prácticas y proyectos relacionados con el diseño y desarrollo de interfaces web.

El objetivo es mantener todos los trabajos organizados y documentados, facilitando tanto su consulta como su evolución a lo largo del curso.

---

## 🎯 Objetivos

Durante el desarrollo de las actividades se trabajan diferentes aspectos relacionados con la creación de interfaces web:

- 🎨 Diseño de interfaces atractivas y funcionales.
- 🧱 Estructuración de páginas mediante HTML.
- 🎨 Diseño y personalización mediante CSS.
- 📱 Creación de interfaces adaptables a diferentes dispositivos.
- 🧩 Organización y reutilización de estilos.
- ⚡ Uso de herramientas y frameworks para el desarrollo web.
- ♿ Introducción a principios de accesibilidad web.
- 🖥️ Aplicación de buenas prácticas de diseño y desarrollo.
- 📂 Organización profesional de proyectos.
- 🔧 Uso de Git y GitHub para el control de versiones.

## 📚 Contenidos

El repositorio se organiza por bloques para facilitar la navegación:

### 🌐 HTML

Ejercicios relacionados con:

- Estructura de documentos HTML.
- Etiquetas semánticas.
- Formularios.
- Tablas.
- Enlaces.
- Imágenes y contenido multimedia.
- Organización de páginas web.

### 🎨 CSS

Ejercicios relacionados con:

- Selectores.
- Colores y tipografías.
- Modelo de cajas.
- Márgenes y padding.
- Posicionamiento.
- Flexbox.
- Grid.
- Animaciones y transiciones.

### 📱 Diseño responsive

Prácticas orientadas a crear páginas adaptables a:

- 💻 Ordenadores.
- 📱 Móviles.
- 📟 Tablets.

### 🧩 Frameworks

Ejercicios y proyectos realizados utilizando herramientas y frameworks de desarrollo de interfaces.
