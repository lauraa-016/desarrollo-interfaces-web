8. Centro de ayuda

Centro de ayuda

¿Qué es HTML?

HTML es el lenguaje utilizado para crear la estructura de las páginas web.

¿Qué es CSS?

CSS es el lenguaje utilizado para definir el diseño y la apariencia de una página web.

¿Qué es JavaScript?

JavaScript es un lenguaje que permite añadir comportamiento e interactividad a las páginas web.

¿Cómo puedo cerrar esta ventana?

Puedes cerrar el centro de ayuda pulsando el botón de cerrar.
